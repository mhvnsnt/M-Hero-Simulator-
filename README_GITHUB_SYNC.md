# Google AI Studio ↔ GitHub Synchronization Guide

To instantly push this architecture to your GitHub repository or pull in external open-source C++ solvers, use the native AI Studio integration.

## How to Push to GitHub
1. Look for the **Save to GitHub** icon in the top-right corner of the AI Studio Build interface.
2. Click it and authorize your GitHub account.
3. Enter a repository name, select public/private, and click **Create Git Repo**.
4. Click **Stage and commit** to push your entire workspace to GitHub.

## How to Pull from GitHub
1. In the main AI Studio prompt input box, click the **+ (Add files)** icon.
2. Select **Import from GitHub**.
3. Point it to the target open-source repository (e.g., a Jolt Physics solver or Godot GDExtension template).
4. The files will be instantly cloned into your AI Studio sandbox for integration.
